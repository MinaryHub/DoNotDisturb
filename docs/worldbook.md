# 설정집 — 《방해 금지 모드》

게임 안 텍스트(독백·간판·안내문·대사)를 쓸 때 기준이 되는 세계관입니다.
수치나 규칙은 `CLAUDE.md`와 `/data`가 정본이고, 여기는 **분위기와 이야기**만 다룹니다.

## 1. 톤

- 세상은 나쁘지 않다. 다만 **너무 시끄럽다.** 사람들은 대체로 친절하고, 그 친절이 버거울 뿐이다.
- 주인공은 사람을 싫어하지 않는다. 사람을 좋아하는 데 에너지가 많이 들 뿐이다.
- 독백은 짧고 구체적으로. 자기 비하("난 왜 이 모양이지") 대신 관찰과 작은 유머("층수 버튼만 보자").
- NPC는 악당이 아니다. 대사는 평범하게 다정하거나, 평범하게 바쁘다.
- 정신질환·내향성을 희화화하지 않는다. 증상 이름(편두통, 홍조)은 쓰되 조롱하지 않는다.

## 2. 무대: 해오름동

수도권 신도시 외곽의 오래된 동네. 아파트 단지와 상가 거리, 오피스 빌딩이 대로 하나를 사이에 두고 붙어 있다.
아침엔 출근 인파, 저녁엔 퇴근 인파와 회식 손님으로 붐비고, 낮과 주말엔 의외로 조용하다.

| 장소 | 이야기 |
|---|---|
| 햇살아파트 | 15년 된 복도식 아파트. 엘리베이터가 하나라 아침마다 이웃과 마주칠 확률이 높다. 3층 복도 끝이 우리 집 |
| 관리사무소 | 공지와 안내문의 발원지. 직원분은 친절하지만 용건이 늘 길다 |
| 해오름 근린공원 | 아파트와 대로 사이 완충지대. 벤치가 몇 개 있고, 평일 오전엔 산책하는 어르신과 고양이뿐 |
| 카페 잔잔 | 이름과 달리 늘 북적인다. 단골 바리스타가 얼굴을 기억해서 곤란하다 |

| 해오름 마트 | 대형 마트. 시식 코너와 셀프 계산대의 긴 줄 |

## 3. 사람들

### 주인공 ("나")
- 이름과 성별을 정하지 않는다. 텍스트는 1인칭 독백과 2인칭 호칭("저기요")으로만 부른다.
- (주)무한상사 기획팀 4년차. 일은 꼼꼼히 잘하지만 회의 발언과 회식이 힘들다.
- 햇살아파트 3층에서 고양이 **보리**와 산다. 취미는 건반 연주, 핸드드립, 창밖 보기.
- 회복 수단을 잘 알고 있다: 조용한 구석, 찬 음료, 익숙한 노래, 고양이.

### 내 사람
- **지우**: 대학 친구. 말을 안 해도 어색하지 않은 유일한 사람. 급할 때 '가짜 긴급 전화'를 걸어 준다(SOS).
- **엄마**: 연락이 잦다. 걱정이 많지만 다정하다.

### 동네와 회사
| 인물 | 프로필 | 한 줄 |
|---|---|---|
| 옆집 아주머니 | `neighbor` | 반찬을 나눠 주고 싶어 한다. 대화가 엘리베이터 도착보다 길다 |
| 관리사무소 직원 | `manager` | 공지사항을 꼭 직접 전하고 싶어 한다 |
| 팀장님 | `boss` | 나쁜 사람은 아니다. 대화를 '짧게'라고 시작해서 길게 끝낸다 |
| 팀 동료들 | `coworker` | 탕비실에 모이는 사람들. 주말 얘기를 묻는다 |
| 고등학교 동창 | `acquaintance` | 이름이 기억 안 나는데 나를 반갑게 기억한다 |
| 전단지·시식 직원 | `flyer`, `sampler` | 일하는 중이다. 거절해도 괜찮다 |
| 옷 매장 점원 | `clerk` | 친절의 거리가 가깝다 |
| 약사 (신규) | `pharmacist` | 증상을 자세히 물어본다. 약은 정확히 준다 |
| 서점 점원 (신규) | `bookseller` | 조용한 사람. 그래도 "찾으시는 책 있으세요?"는 묻는다 |
| 택배 기사님 (신규) | `courier` | 늘 바쁘다. 문 앞에 두고 가면 좋겠는데 사인을 받아야 한다 |
| 설문 조사원 (신규) | `surveyor` | "잠깐 1분만요." 1분은 아니다 |
| 이웃집 아이 (신규) | `kid` | 큰 소리로 인사한다. 받아 주면 활짝 웃는다 |

## 5. 이름 짓기 규칙

- 실제 브랜드·체인 이름을 쓰지 않는다. 동네 이름(해오름)이나 순한 일반명사를 쓴다.
- 간판은 짧게(2~7자). 안내문은 실제 아파트·회사 안내문 말투를 살짝 비튼다.
