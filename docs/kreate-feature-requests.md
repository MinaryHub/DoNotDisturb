# Kreate 기능 요청서 — 《방해 금지 모드》 개발용

게임 개발 중 Kreate에 필요해진 기능을 정리합니다. 게임 쪽은 각 항목의 **임시 대안**으로 동작하므로 급하지 않은 순서대로 적었습니다.

| # | 기능 | 필요한 이유 | 현재 임시 대안 | 우선순위 | 상태 |
|---|---|---|---|---|---|
| 1 | **오브젝트 사용자 정의 속성 → glTF 노드 `extras` 내보내기** | 트리거 eventId, 자극 강도 등을 이름 대신 속성 패널에서 편집. 이름이 길어지고 오타 위험이 큼 | 이름 뒤 `__key=value` | 중 | 요청 |
| 2 | GLB 내보내기에서 오브젝트 이름 **원문 보존** 확인 (`=`, `.`, `_` 등 특수문자) | 이름 속성 방식이 이 문자에 의존 | 실제 내보낸 파일로 확인 필요 | **높음** | 확인 필요 |
| 3 | GLB 내보내기 시 **Z-up → Y-up 변환** 확인 | 게임 좌표계는 glTF 표준(Y-up, −Z 정면) | 검증 도구가 축 오류 감지 | **높음** | 확인 필요 |
| 4 | 빈 오브젝트(Empty)를 glTF 노드로 내보내기 | `SPAWN_`, `PATH_`가 메시 없는 위치 표시 | 작은 메시로 대체 가능(게임에서 숨김) | 중 | 확인 필요 |
| 5 | 오브젝트 이름 접두어 일괄 지정 / 접두어별 색 표시 | 레벨 제작 시 `COL_`·`NAV_` 등 구분이 쉬움 | 수동 이름 변경 | 낮음 | 요청 |
| 6 | 지정 폴더로 빠른 재내보내기 (단축키 1회) | 게임의 핫 리로드와 맞물려 반복 작업 속도 향상 | 매번 내보내기 대화상자 | 낮음 | 요청 |

## 세부 내용

### 1. extras 내보내기
- 형식: 노드의 `extras.dnd` 객체. 예: `{ "dnd": { "eventId": "landlordCall", "once": true } }`
- 값 타입: 문자열, 숫자, 불리언이면 충분합니다.
- 게임은 extras가 있으면 이름 속성보다 우선해서 읽도록 이미 구현되어 있습니다.

### 2~4. 확인 방법
Kreate에서 아래 오브젝트로 작은 테스트 씬을 만들어 `assets/kreate/levels/kreate_check.glb`로 내보낸 뒤 `npm run validate:assets`를 실행하면 결과가 나옵니다.
- 바닥 박스 `NAV_floor`, `COL_floor`
- 박스 `TRG_test__eventId=hello__once=true`, `ZONE_test__stimulus=crowd__intensity=0.6`
- 빈 오브젝트 `SPAWN_player` (정면을 −Y 방향으로 회전시켜 두기 — Kreate Z-up 기준 "앞")
