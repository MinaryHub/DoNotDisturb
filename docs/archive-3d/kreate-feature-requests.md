# Kreate 기능 요청서 — 《방해 금지 모드》 개발용

게임 개발 중 Kreate에 필요해진 기능을 정리합니다. 게임 쪽은 각 항목의 **임시 대안**으로 동작하므로 급하지 않은 순서대로 적었습니다.

## 요청

| # | 기능 | 필요한 이유 | 현재 임시 대안 | 우선순위 |
|---|---|---|---|---|
| 1 | **오브젝트 사용자 정의 속성 → glTF 노드 `extras` 내보내기** | 트리거 eventId, 자극 강도 등을 이름 대신 속성 패널에서 편집. 이름이 길어지고 오타 위험이 큼 | 이름 뒤 `__key=value` (동작 확인됨) | 중 |
| 2 | 오브젝트 이름 접두어 일괄 지정 / 접두어별 색 표시 | 레벨 제작 시 `COL_`·`NAV_` 등 구분이 쉬움 | 수동 이름 변경 | 낮음 |
| 3 | 지정 경로로 빠른 재내보내기 (단축키 1회) | 게임의 핫 리로드와 맞물려 반복 작업 속도 향상 | 매번 내보내기 | 낮음 |
| 4 | "보이는 메시 + 충돌체" 짝 만들기 (복제 후 접두어만 바꾼 사본 생성) | `VIS_wall`/`COL_wall`처럼 같은 모양을 두 번 만드는 일이 잦음 | 수동 복제 + 이름 변경 | 낮음 |

### 1. extras 내보내기 세부
- 형식: 노드의 `extras.dnd` 객체. 예: `{ "dnd": { "eventId": "landlordCall", "once": true } }`
- 값 타입: 문자열, 숫자, 불리언이면 충분합니다.
- 게임은 extras가 있으면 이름 속성보다 우선해서 읽도록 이미 구현되어 있습니다.

## 확인 완료 (2026-10-21, 실제 Kreate GLB 내보내기로 검증)

| 항목 | 결과 |
|---|---|
| 오브젝트 이름 원문 보존 (`=`, `.`, `__`) | ✔ 그대로 보존 |
| Z-up → Y-up 변환 | ✔ Kreate (x, y, z) → glTF (x, z, −y). Kreate +Y가 게임 정면(−Z) |
| 빈 오브젝트(Empty) 내보내기 | ✔ 메시 없는 노드로 내보냄 |
| 이름 중복 처리 | 두 번째부터 `.001` 접미어 — 게임은 무시하고 검증 도구가 경고 |
| 사용자 정의 속성(extras) | ✘ 지원 기능 없음 → 요청 1 |
| 선택 확장 `KREATE_ngons` | 게임·검증 도구 모두 무시하고 정상 로드 (조치 불필요) |
