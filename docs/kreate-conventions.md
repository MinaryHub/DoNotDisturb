# Kreate 제작 규칙 — 《방해 금지 모드》

Kreate에서 레벨과 에셋을 만들 때 지켜야 할 규칙입니다. 이 규칙만 지키면 GLB를 `assets/kreate/`에 저장하는 것만으로 게임에 충돌·트리거·스폰·NPC 경로가 자동으로 생깁니다.

---

## 1. 내보내기

| 항목 | 규칙 |
|---|---|
| 형식 | **GLB** (`.glb`) |
| 저장 위치 | `assets/kreate/` 아래 종류별 폴더 (아래 표) |
| 축 | Kreate에서는 **평소대로 Z-up으로 작업**하면 됩니다. GLB 내보내기가 게임 좌표(Y-up)로 자동 변환합니다 (2026-10-21 확인). **Kreate의 +Y 방향이 게임의 정면**입니다. |
| 단위 | **1 = 1m**. 레벨이 수백 m 이상으로 나오거나 소품이 1cm 미만이면 단위 오류로 경고합니다. |
| 원점 | 캐릭터·소품은 **바닥 중앙** |
| 재질 | 색·거칠기·금속성(PBR 기본)만 사용. 화면 왜곡 효과는 게임이 후처리로 넣습니다. |
| 텍스처 | 최대 2048px, 소품은 1024px 이하 |

### 폴더와 에셋 종류

| 폴더 | 종류 | 삼각형 예산 |
|---|---|---|
| `levels/` | 레벨 맵 (VIS 오브젝트 1개당) | 10,000 |
| `props/` | 소품 | 2,000 |
| `characters/` | NPC | 8,000 |
| `characters/*_crowd.glb` | 군중용 저폴리 NPC | 1,500 |
| `fp/` | 1인칭 손 | 6,000 |

예산은 `data/assetBudget.json`에서 조정합니다.

## 2. 오브젝트 이름 접두어 (레벨)

오브젝트 이름 앞에 접두어를 붙이면 게임이 역할을 자동으로 인식합니다. **접두어가 붙은 오브젝트는 게임에서 보이지 않습니다** (`VIS_`만 예외).

| 접두어 | 용도 | 만드는 법 |
|---|---|---|
| `VIS_` 또는 접두어 없음 | 보이는 메시 | 평소처럼 모델링 |
| `COL_` | 충돌체 (플레이어가 통과 못 함) | 보이는 메시를 복제하거나 단순한 박스로 감싸기 |
| `NAV_` | NPC가 걸을 수 있는 바닥 | 바닥면 메시 |
| `LOS_` | NPC 시야를 가리는 물체 | 화분·칸막이처럼 **시선만** 가리는 것. 벽·기둥 같은 `COL_`은 따로 안 붙여도 시야를 가립니다(아래 가정 참고) |
| `HIDE_` | 은신 지점 (발각 반경 감소) | 영역을 덮는 박스 |
| `SAFE_` | 세이프 존 (화장실 칸 등) | 영역을 덮는 박스 |
| `TRG_` | 이벤트 트리거 | 영역을 덮는 박스 + `eventId` 속성 |
| `SPAWN_` | 시작 위치 | 빈 오브젝트(Empty). **Kreate의 +Y 방향이 바라보는 방향** — Z축으로 회전시켜 방향을 정함 |
| `PATH_` | NPC 순찰 지점 | 빈 오브젝트를 `PATH_<npcId>_01`, `_02` … 순서로 |
| `ZONE_` | 군중·소음 같은 지속 자극 구역 | 영역을 덮는 박스 + `stimulus` 속성 |

- 접두어는 **대문자**로, 오브젝트마다 각각 붙입니다. 부모에만 붙이면 자식에게 적용되지 않습니다.
- `HIDE_`/`SAFE_`/`TRG_`/`ZONE_`은 **메시가 있어야** 합니다. 메시의 바운딩 박스(회전 포함)가 영역이 됩니다.
- 레벨에는 반드시 `SPAWN_player`가 있어야 합니다. NPC 시작 위치는 `SPAWN_npc_<id>`.
- 보이는 벽과 충돌체가 같은 모양이라면 `VIS_wall`과 `COL_wall`을 겹쳐 두 개 만듭니다.

## 3. 속성 붙이기

Kreate에는 현재 사용자 정의 속성(glTF extras) 기능이 없으므로, **이름 뒤에 `__키=값`** 형식으로 붙입니다 (밑줄 두 개). Kreate 이름 변경 칸에 그대로 입력하면 되고, `=`·`.` 문자도 GLB에 그대로 보존됩니다 (2026-10-21 확인).

```
TRG_phone__eventId=landlordCall__once=true
ZONE_lobby__stimulus=crowd__intensity=0.6
SAFE_toilet__capacity=1__noiseAfterSec=45
COL_table__shape=box
```

| 접두어 | 속성 | 필수 | 설명 |
|---|---|---|---|
| `TRG_` | `eventId` | ✔ | 스테이지 스크립트(`data/stages/stageNN.json`)에서 찾을 이벤트 이름 |
|  | `once` |  | `true`면 한 번만 발동 |
| `ZONE_` | `stimulus` | ✔ | 자극 종류 (`crowd`, `noise` 등) |
|  | `intensity` |  | 0~1 강도 |
| `SAFE_` | `capacity` |  | 동시에 숨을 수 있는 인원 |
|  | `noiseAfterSec` |  | 이 시간을 넘기면 노크 이벤트 |
| `HIDE_` | `detectScale` |  | 0~1, 발각 반경 배율 |
| `COL_` | `shape` |  | `box`면 박스 충돌체(가볍고 안정적), 기본은 메시 그대로 |
| `PATH_` | `waitSec` |  | 이 지점에서 머무는 시간 |

- 값은 `true`/`false`, 숫자, 문자열을 씁니다.
- 생략한 수치는 게임의 `/data` 설정값이 사용됩니다.
- 나중에 Kreate가 extras를 지원하면 `{ "dnd": { "eventId": "landlordCall" } }` 형식도 자동으로 읽습니다(이름 속성보다 우선).

### 이름 중복 주의
Kreate는 같은 이름이 있으면 `TRG_phone.001`처럼 번호를 붙입니다. 게임은 번호를 무시하므로 `SPAWN_player`가 두 개면 충돌이 생깁니다. 검증 도구가 알려줍니다. 소수 값 바로 뒤에 번호가 붙는 경우(`intensity=0.6.001`)도 처리하지만, `intensity=0.600`처럼 소수점 아래 세 자리 값은 번호로 오해하지 않도록 그대로 값으로 읽습니다.

## 4. 확인 방법

```bash
npm run validate:assets     # 접두어 오타, 필수 노드 누락, 속성 오류, 예산·단위·축 검사
npm run dev                 # 게임 실행 → 디버그 패널(F1)에서 오버레이로 확인
```

- 개발 서버가 켜져 있으면 Kreate에서 GLB를 다시 내보내는 순간 게임이 현재 레벨을 자동으로 다시 불러옵니다.
- 다른 레벨 보기: `http://localhost:5173/?level=levels/stage01.glb` 또는 디버그 패널의 경로 입력.

### 디버그 오버레이 색
| 색 | 의미 |
|---|---|
| 초록 와이어 | `COL_` 충돌체 |
| 주황 와이어 | `LOS_` 시선 차단 |
| 노랑 / 하늘 / 파랑 / 분홍 상자 | `TRG_` / `SAFE_` / `HIDE_` / `ZONE_` (들어가면 진해짐) |
| 초록·빨강 화살표 기둥 | `SPAWN_player` / NPC 스폰 |
| 빨간 선 | `PATH_` 순찰 경로 |
| 청록 면 | 생성된 내비메시 |

## 5. 캐릭터 (Phase 1 이후 사용)

- 애니메이션 클립 이름: `Idle`, `Walk`, `TurnHead`, `Nod`, `Reach`, `Talk`, `Sit`, `Laugh`
- 스켈레탈 애니메이션을 쓰지 않는 경우: 모델을 `HEAD`, `BODY`, `ARM_L`, `ARM_R` 오브젝트로 나눠 주면 게임이 코드로 움직입니다.
- 1인칭 손은 `FP_HANDS`.
- 군중용은 파일 이름 끝에 `_crowd`.

---

## 현재 적용된 가정 (확정 필요 시 알려주세요)

1. NPC 시야는 `COL_`과 `LOS_` **둘 다**에 가려집니다. `LOS_`는 "통과는 되지만 보이지 않게 하는 것"을 위한 추가 표시입니다.
2. 내비메시는 `NAV_` 바닥과 `COL_` 장애물을 함께 넣어 만듭니다. `COL_` 윗면(책상 위 등)도 걸을 수 있는 면으로 계산되지만, 바닥과 이어지지 않으면 NPC가 갈 수 없는 고립 영역이라 문제가 없습니다.
3. 볼륨(`TRG_` 등)은 메시의 회전된 바운딩 박스로 근사합니다. 박스가 아닌 모양은 상자로 감싸집니다.
